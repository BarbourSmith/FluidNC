# v1.25.0 Firmware Release

Version 1.25 improves calibration and Park workflows, and addresses several
issues that could leave the machine in an unusable state.

## Highlights

- Added a manual anchor-location solver and improved the calibration simulation
  with the Levenberg–Marquardt algorithm ([#1064](https://github.com/MaslowCNC/Maslow_4/pull/1064), [#1057](https://github.com/MaslowCNC/Maslow_4/pull/1057)).
- Made Park movement safe in both millimetres and inches, while restoring the
  operator's previous unit mode afterward ([#1062](https://github.com/MaslowCNC/Maslow_4/pull/1062), [#1072](https://github.com/MaslowCNC/Maslow_4/pull/1072)).
- Improved alarm recovery so clearing an alarm no longer requires a power
  cycle, with an explicit prompt to re-establish machine position ([#1087](https://github.com/MaslowCNC/Maslow_4/pull/1087), [#1091](https://github.com/MaslowCNC/Maslow_4/pull/1091)).

## Fixes

- Fixed the Release Tension button becoming unresponsive after a Home-to-Park
  sequence ([#1056](https://github.com/MaslowCNC/Maslow_4/pull/1056)).
- Fixed successful probe operations producing a `ZNaN` retract command ([#1082](https://github.com/MaslowCNC/Maslow_4/pull/1082), [#1086](https://github.com/MaslowCNC/Maslow_4/pull/1086)).
- Fixed routine alarms incorrectly latching the red LED and preventing further
  movement ([#1087](https://github.com/MaslowCNC/Maslow_4/pull/1087)).

## User interface and documentation

- Clarified Park X/Y absolute-coordinate and Park Z clearance semantics in the
  tablet UI ([#1059](https://github.com/MaslowCNC/Maslow_4/pull/1059)).
- Updated setup instructions and moved the layout simulator into the
  documentation ([#1080](https://github.com/MaslowCNC/Maslow_4/pull/1080), [#1077](https://github.com/MaslowCNC/Maslow_4/pull/1077)).

## Upgrade notes

After clearing an alarm, verify the machine position before cutting. Run the
Retract/Extend cycle when prompted by the UI.
